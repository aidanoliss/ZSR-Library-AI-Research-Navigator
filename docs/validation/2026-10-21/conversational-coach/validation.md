# Conversational research coaching validation

October 21, 2026. Feature: source-free, conversational library research coaching alongside the existing authenticated abstract discussion route.

- Clean release checkout: `npm run qa:release` passed 592 tests, resource configuration audit, 56/56 strict planner cases and 1,232/1,232 planner assertions, synthetic HTTP/browser fixture self-test, and production build. The build retains its existing large-bundle advisory. These are regression checks, not a factual-accuracy rate or librarian approval.
- After tightening the neutral-question generation instructions, all 38 backend chat/coach tests passed again. The prompt change does not prove neutral output in every case.
- Real Gemini smoke test: source-free sanctions planning responded as coaching; a follow-up about civilian health in Russia after 2014 retained that context and offered possible angles instead of asserting study findings. A method question initially used fallback; a subsequent raw-provider diagnostic validated successfully. The method fallback now supplies the exact relevant curated guide summary, with an explicit fallback label, rather than a generic restart.
- Actual localhost UI with Gemini: a six-source, first-year Russia/2014 request worked without attachments. A follow-up specifying essential medicines retained country/time and offered two search-question drafts. One draft presupposed a causal effect; generation instructions were tightened to prefer neutral relationships, possible explanations, and “if any.” This observation is a known semantic limitation, not hidden by the passing tests.
- Isolated synthetic UI on port 3014: a chat-only conversation created a sidebar session and restored both messages and the chat view after reload. A draft transferred into Search for review without executing. Private-mode chat worked and cleared after reload. No Export chat button appeared.

The seven guide summaries are developer-curated paraphrases of official pages. They are not live retrieval, institutional policy verification, full-text research, or librarian approval. Exact guide IDs/URLs and server-authored definitions prevent model-invented guide references in that path. Generated procedural advice is still fallible; pattern checks are not semantic entailment or a guarantee against hallucination, bias, or prompt injection. Questions about study findings retain authenticated source/abstract checks; source presence and exact quotations do not prove that an interpretation follows from the evidence.

Before a student pilot, have a ZSR librarian review the seven guide summaries and evaluate varied multi-turn coaching transcripts, including narrow methods questions, leading prompts, changing constraints, and handoff to source search. Revisit any systematic refusal/fallback or scope failure observed in that review.
