Descriptions are paraphrases of profile text. No claims from model output, provider abstracts, third-party expert aggregators, or search-result titles are used as expertise evidence. The record review window ends 2027-01-24. Runtime checks suppress records outside the date window, off-domain profile/evidence links, unreviewed/inactive entries, duplicate people and records from other institutions. A lack of a match means the small pilot has no supported suggestion, not that Wake lacks relevant faculty.

Tests validate exact positive/negative topic scenarios, exclusion handling, student-corrected concepts, source URL safety, future/stale checks, deduplication, two-faculty limit and institution isolation. This is a rule-based fixture validation, not a human-scored recommendation accuracy rate.
