# Research guidance pilot guide


### Research guidance pilot tasks (October 2026)

1. Try an ambiguous sanctions or student-population question. Select a clarification, then repeat with Skip. Check that the resulting query reflects the intended question without adding instructional words.
2. Mark a population or location Preferred under Required criteria & preferences. Run the search twice. Confirm the preference remains visible and is not silently restored as a hard filter. Do not relax assignment requirements without permission.
3. Read Fit to your request on a source card. Open Check basis and compare its statement with the provider abstract and original source. Record any unsupported or misleading fit label.
4. Use Find more like this. Compare Related works, References, and Citing works. Distinguish a topical search result from a provider-reported citation relationship. Check the sample limit and unavailable states.
5. Save a source and add an Evidence notebook entry with a claim, exact passage, location, and limitations. Confirm it only after reading the source; edit the entry and verify it needs checking again. Export a workspace backup and inspect its evidence and warnings.
6. Give source feedback using a specific reason, inspect Feedback review, and export only if willing to share the included query and source metadata. Exports are unreviewed judgments, not accuracy labels. A librarian or independent reviewer must grade them before use in an evaluation set.
7. Open What this search covered. Identify which providers completed a lookup, which failed or were not searched, and which databases are recommendations only.

Test once in a private session on a shared computer. Reloading ends that session's in-memory research; downloaded exports remain on disk. Automated tests and these task completions do not establish source relevance accuracy, full-text grounding, or comprehensive literature coverage.
